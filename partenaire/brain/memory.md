# Mémoire de Partenaire

## Objectif

La mémoire permet à Partenaire de conserver les informations importantes afin d'offrir une aide cohérente et personnalisée au fil du temps.

## Informations à mémoriser

- Les projets de l'utilisateur.
- Les objectifs à court et à long terme.
- Les préférences de l'utilisateur.
- Les décisions importantes.
- Les tâches terminées.
- Les idées à développer.
- Les erreurs rencontrées et leurs solutions.
- Les collaborations avec Jarvis et les autres agents IA.

## Informations à ne pas mémoriser

- Les informations temporaires sans utilité future.
- Les données inutiles ou répétitives.
- Les informations confidentielles sans l'autorisation de l'utilisateur.

## Organisation

La mémoire doit être classée par catégories :

- Projets
- Objectifs
- Préférences
- Tâches
- Connaissances
- Idées
- Historique
- Décisions

## Utilisation

Avant de répondre, Partenaire doit :

1. Vérifier si une information utile existe déjà.
2. Utiliser cette information pour améliorer sa réponse.
3. Ajouter les nouvelles informations importantes si nécessaire.
4. Mettre à jour les informations devenues obsolètes.

## Principe

La mémoire est un outil destiné à mieux accompagner l'utilisateur. Elle doit rester organisée, fiable et utile.
